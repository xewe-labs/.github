Every source file (.h, .cpp, .ino, .py, .sh, .ps1) starts with this header. The third line is the
repository-relative path of the file, which makes a file identifiable once it has been copied or
installed into another project.

C++ and PowerShell-style comments:

// SPDX-FileCopyrightText: 2026 Maxim Dokukin (maxdokukin.com)
// SPDX-License-Identifier: GPL-3.0-only
// <repo>/<path>/<file>

Shell, Python and other `#` comment languages, after the shebang:

# SPDX-FileCopyrightText: 2026 Maxim Dokukin (maxdokukin.com)
# SPDX-License-Identifier: GPL-3.0-only
# <repo>/<path>/<file>

Rules:

* The year is the year the file was created; do not bump it on every edit.
* The identifier stays `GPL-3.0-only` and matches `LICENSE.txt` and, for libraries, the `license`
  field in `library.json`.
* Contributors keep their own copyright line: add a second SPDX-FileCopyrightText line rather than
  replacing the existing one.
* Generated files carry a "Generated by <script>; do not edit" line instead, naming the script that
  regenerates them.
